This project explores the power of diffusion models for image generation and manipulation. In Part A, we implement diffusion sampling loops, use pre-trained models for various tasks including inpainting and creating optical illusions, and experiment with text-to-image generation using DeepFloyd IF. In Part B, we train our own diffusion model from scratch, using a U-Net architecture to generate handwritten digits from noise. We explore various modifications such as time conditioning, class conditioning, and classifier-free guidance to improve the quality and consistency of the generated digits.

Part 1: Sampling Loops

1.1 Implementing the Forward Process

We implement the forward process that adds noise to clean images, creating progressively noisier versions that simulate the diffusion process. To add noise, we follow the formula as given in the project website.

1.2 Classical Denoising

We attempt to denoise the noisy images using a Gaussian blur filter. However, we see that this does not work very well since the diffusion process introduces complex noise patterns that standard filters cannot effectively remove.

1.3 One-Step Denoising

To have more accurate denoising, we implement one-step denoising using the diffusion model to directly predict clean images from noisy inputs. This approach provides a direct mapping from noisy to clean images in a single forward pass, but we notice that noisier images still suffer from a lack of detail when denoised.

1.4 Iterative Denoising

For even better quality, we implement iterative denoising that gradually removes noise over multiple steps, following the reverse diffusion process. At each step, we use the denoised image from the previous step as input to the denoising model, which outputs noise that we use to partially denoise the image further. By doing this, we can achieve higher quality results than single-step denoising.

1.5 Diffusion Model Sampling

Using the same function from 1.4, we start from completely random noise and iteratively denoise to generate new images. The results show realistic images, although the quality is not that great.

1.6 Classifier-Free Guidance (CFG)

We implement classifier-free guidance to improve the quality and text-alignment of generated images by combining unconditioned generations (with an empty prompt) and conditional generations, conditioned on the prompt "a high quality photo". We see that these images are much better than the ones from the previous part.

1.7 Image-to-Image Translation

Now, using our CFG implementation, we implement image-to-image translation by adding noise to existing images and then denoising conditioned on the text prompt "a high quality photo". We notice that for noised images closer to the original (a higher i_start value), the results are more faithful to the original image, while lower values produce more creative outputs.

1.7.1 Hand-Drawn and Web Images

Using the same image-to-image technique as earlier, we apply it to hand-drawn and web images and observe some cool generations from different starting points!

1.7.2 Inpainting

We implement inpainting to fill in missing or masked regions of images using diffusion models. This is done by forcing the image at each timestep to remain consistent with the unmasked region (with noise added through the forward process) while generating the masked portion through the denoising process.

1.7.3 Text-Conditional Image-to-image Translation

So far, we have been using the original image as a sort of guide, and then adding/removing noise to generate unique variations of the input while conditioning on the prompt "a high quality photo". Now, we condition on other unique text prompts to better guide the denoising process towards desired outputs, while preserving some similarities with the original image.

1.8 Visual Anagrams

We generate visual anagrams, images that depict one scene when viewed upright and a different scene when viewed upside down. During diffusion, at each denoising step we evaluate two prompts: one on the current image and one on a vertically flipped version of the image. We then average the predicted noise from both prompts and use this combined noise estimate to update the image. By incorporating information from both orientations at every step, the model is encouraged to satisfy both prompts simultaneously, producing the anagram effect.

1.9 Hybrid Images

Similar to Part 1.8, we generate hybrid images that reveal different content at different viewing distances. This is achieved by combining the low-frequency components of one image with the high-frequency components of another. During diffusion, at each denoising step we separately filter the predicted noise tensors: a low-pass filter is applied to the noise from one prompt, and a high-pass filter to the noise from the other. The filtered noise estimates are then combined to form a single noise update.

1.2.2 Out-of-Distribution Testing

Since we only trained on sigma=0.5, we test our denoiser on other levels of noise. As expected, the denoiser performs poorly on higher noise levels. However, it performs well on lower noise levels, motivating the need for training on higher levels of noise to improve generalization.

1.2.3 Denoising Pure Noise

As mentioned in the previous part, the need arises to train on higher levels of noise, so we try training on pure noise every time. However, rather than performing well, we see that the denoiser converges on the same output regardless of input noise. However, the training loss did go down to a fairly reasonable value. This is an indication of mode collapse, a common pitfall of generative models.

Part 2: Training a Flow Matching Model

Adding Time Conditioning to UNet

To enable the UNet to handle different noise levels during training, we add time conditioning. This allows the model to learn how to denoise at various noise levels, which is essential for flow matching. The time input here essentially functions as a marker that tells the model what noise level it is currently at, allowing it to adapt its denoising strategy accordingly.

2.2 Training the UNet

Learning from the mistakes in Part 1, we now train a time-conditioned UNet for denoising. For each image, we noise it to a different level and train the UNet to denoise it back to the original. 2.4 Adding Class-Conditioning to UNet

To give us more control over the image generation, we modify the UNet to take class labels as additional input. This allows us to condition the generation process on specific classes, leading to more targeted and controllable image synthesis. However, to allow us to generate unconditioned images as well, we train with a random chance of dropping the class conditioning vector.

2.5 Training the UNet

We train this UNet with a similar procedure as the time-conditioned UNet, but we also incorporate the class conditioning mentioned in Part 2.4 during training. Notably, we achieve slightly better loss although it is still quite close to the time-conditioned version.

2.6 Sampling from the UNet

Now, we sample with class-conditioning and use classifier-free guidance as in Part A to improve the quality of generated images. Additionally, we see if we can remove the scheduler and achieve comparable performance. For this comparison, we compare outputs from two models both trained for 5 epochs: one with the scheduler and one without. In this case, removing the scheduler creates slightly worse images, but the loss curves are relatively the same. However, in cases where there is a discrepancy, we can switch to a lower fixed learning rate for improved stability that somewhat mimics what the exponential scheduler eventually does.
